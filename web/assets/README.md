# Optional artwork

The title screen can use your own pictures. Put them in this folder with these names:

| File | Used for |
|---|---|
| `fondo.jpg` | title screen background (cover, any size) |
| `btn-play.png`, `btn-settings.png`, `btn-credits.png` | the three title buttons |
| `barra.png` | the frame of the loading bar |
| `dsu.png` | icon of the DSU Remote tab |

The included pictures are the project's own: the buttons, loading bar and DSU icon were made with AI
tools and the background is fan art. Replace any of them with your own pictures of the same name if you
like; if a file is missing the page draws plain Wii-style buttons and a gradient background instead.
